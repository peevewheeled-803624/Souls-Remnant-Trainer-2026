## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Soul's Remnant**. A gameplay trainer for Soul's Remnant that provides configurable combat, movement, progression, and inventory assistance for controlled testing and private use.

**Target Audience:** Players, testers, and mod users who want to experiment with character builds, combat balance, equipment upgrades, and progression in Soul's Remnant.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

3. The folder structure should look like this:

## 📖 Detailed Feature Guide

### Movement & Exploration

Launch the game and load into a playable area before activating movement options. Use the movement speed control for traversal and platforming tests, then disable it before entering normal online activities.

### Tools & Inventory

Open the character inventory before using item-related functions. Select a supported item, activate the quantity editor, and verify the result before crafting, upgrading, trading, or changing equipment.

### World & Environment

Soul's Remnant is built around exploration, quests, gathering, crafting, social areas, guild activities, dungeons, and player-driven content. Use world-related trainer options only for controlled testing and avoid interfering with shared multiplayer spaces.

### Combat & Weapons

Enter combat before enabling invulnerability, damage, or experience options. Test settings against regular monsters first, then use them carefully in dungeons and boss encounters. Disable all combat modifications before returning to standard multiplayer play.
